# Real-Time Movie Recommendation Engine

An end-to-end, two-stage movie recommendation system featuring candidate retrieval via deep learning embeddings, contextual re-ranking, and event-driven real-time user session adaptation.

## Tech Stack
- **Machine Learning**: PyTorch, LightGBM
- **Backend & Serving**: FastAPI, Python 3.10+
- **Data & Storage**: PostgreSQL, Redis, Qdrant Vector Database
- **Streaming & Infrastructure**: Apache Kafka, Docker Compose
